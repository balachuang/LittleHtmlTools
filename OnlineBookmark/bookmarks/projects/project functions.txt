DA
- 開單
  - project admin 有權限開單.
  - 開單時要在 signoff person 欄位輸入所有要簽核的人, 所有同仁都可以被加入到這個欄位中.
  - 簽核單內容包含下列種類欄位:.
    - 下拉選單: fab, main category, sub category.
	  fab, main category 選項內容固定,
	  sub category 選項內容會隨 main category 而變.
	- rich edit 欄位, 記錄單子內容.
	- attachment.
	- pure text 欄位.
- 簽核
  - 開單後先把 assignee 設定給開單者, 由開單者再次確認內容無誤.
  - 開單者確認無誤後把單子往下推. assignee 設定給 signoff person 欄位中記錄的第一個人.
  - assignee approve 後, 如果 signoff person 還有下一個人, 則把 assignee 設定給下一個人, status 不變.
  - assignee approve 後, 如果 signoff person 中已經沒有下一個人, status 改成 close, 簽核結束.
  - 簽核過程中, assignee 不能編輯單子內容
  - creator 可以在簽核過程中改變 assignee
- 查詢
  - project admin, project user, project viewer 有權限可以查詢及觀看相同 fab 的簽核單內容.
  - signoff person 欄位內的人員可以查詢及觀看該張簽核單內容.
